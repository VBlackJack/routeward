# RouteWard v2026.1123.00

La fenêtre de RouteWard fonctionne désormais sous Linux, avec un lanceur dans le menu et une aide claire quand le service est injoignable. La ligne de commande parle la langue de votre système.

## Corrigé

- **Linux : la fenêtre s'ouvre et affiche RouteWard.** Jusqu'ici, l'application se fermait aussitôt sous Wayland (la session par défaut d'Ubuntu) et affichait une fenêtre vide sous X11. Elle fonctionne maintenant dans les deux cas.
- **Linux : un message clair si la fenêtre ne peut pas s'ouvrir.** Une fenêtre d'erreur explique quoi faire et où se trouve le journal, au lieu d'une indication sur Microsoft Edge WebView2 écrite seulement dans le journal.

## Ajouté

- **Linux : RouteWard dans le menu des applications.** Le paquet installe un lanceur et les icônes de RouteWard : vous démarrez RouteWard comme n'importe quelle application et pouvez le garder dans le dock.
- **Linux : de l'aide quand le service est injoignable.** RouteWard vous dit lequel de ces cas s'applique et la commande à taper :
  - votre compte n'a pas encore le droit de parler au service : `sudo usermod -aG routeward $USER`, puis déconnectez-vous et reconnectez-vous ;
  - le service ne tourne pas : `sudo systemctl enable --now routeward`.
- **README : "Installation sous Linux"** avec ces étapes.

## Modifié

- **La ligne de commande suit la langue de votre système.** Elle répondait en français partout. Elle utilise maintenant `--locale` ou `ROUTEWARD_LOCALE` si vous les indiquez, sinon la langue de votre système.
- **Paquet Linux :** WebKitGTK (`libwebkit2gtk-4.1-0`) et GTK (`libgtk-3-0`) sont désormais requis, `apt` les installe avec RouteWard.
- **La première fenêtre tient dans l'écran** sur les petits affichages, sur tous les systèmes.

## Notes de mise à niveau

- Linux : le service RouteWard reste arrêté après une première installation. Activez-le une fois avec `sudo systemctl enable --now routeward` et ajoutez votre compte au groupe `routeward` (voir plus haut). Les mises à jour conservent l'état actuel.
- Les scripts qui lisent la sortie française de la ligne de commande doivent passer `--locale fr`. La sortie JSON (`--json`) ne change pas.

## Mise à niveau et vérification

- Windows : téléchargez `routeward-2026.1123.0-windows-x64.msi` (met à niveau les builds précédents via `MSI ProductVersion 26.11.2300`) ou `routeward-2026.1123.0-windows-x64.zip`.
- Linux : `sudo apt install ./routeward_2026.1123.0_amd64.deb`.
- Vérifiez les sommes de contrôle avec `SHA256SUMS.txt` ou les fichiers `.sha256` individuels.
