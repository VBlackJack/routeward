# RouteWard v2026.1115.00

Première version publiée de RouteWard, routeur proxy système et pare-feu sortant par processus écrit en Rust pour Windows et Linux.

## Nouveautés principales

- **Routage transparent au niveau OS** : Interception TCP, UDP et DNS par processus sous Windows (WinDivert) et Linux (`nftables` et `TPROXY`) en IPv4 et IPv6.
- **Protocoles amont et authentification** : Prise en charge de SOCKS5 (TCP et UDP ASSOCIATE), SOCKS4 / SOCKS4a, HTTP CONNECT et HTTPS CONNECT (TLS avec option `tlsSkipVerify`), incluant l'authentification Windows SSPI (`Negotiate` / `NTLM`).
- **Chaînes, bascule et Kill Switch** : Routage direct, blocage, chaînes multi-sauts, groupes à bascule et protection contre les fuites via Fake-IP (`198.18.0.0/15`), DNS-over-TCP, blocage QUIC/LLMNR/mDNS/NetBIOS et mode kill switch strict.
- **Routage par motifs pour Microsoft Edge** : Inspection TLS SNI et en-tête `Host:` HTTP, exclusions `!pattern`, import JSON FoxyProxy et serveur PAC loopback local (`http://127.0.0.1:10811/proxy.pac`) avec configuration optionnelle de `AutoConfigURL` sous Windows.
- **Interface desktop, service et CLI** : Application `routeward-desktop` (modes Simple et Expert, sélecteur visuel d'applications système, profils nommés, barre d'état système, flux temps réel avec export CSV/JSON, interface FR/EN), service Windows SCM, `routeward ctl` et `routeward cleanup`.

## Installation sous Windows et vérification

- Télécharger `routeward-2026.1115.0-windows-x64.msi` (installateur machine avec raccourci Menu Démarrer) ou `routeward-2026.1115.0-windows-x64.zip`.
- Contrôler les empreintes SHA-256 via `SHA256SUMS.txt` ou les fichiers `.sha256`.
- Note WinDivert : si l'installateur `.msi` standard ne contient pas WinDivert embarqué, exécuter `fetch-windivert.ps1 -OutputDirectory "C:\Program Files\RouteWard"` dans un PowerShell administrateur pour télécharger et vérifier WinDivert 2.2.2-A.
