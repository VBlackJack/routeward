# RouteWard v2026.1122.01

La mise à jour depuis une ancienne version garde désormais votre protection active.

## Corrigé

- **La mise à jour garde la protection active** : si vous mettez à jour depuis la v2026.1121.01 ou une version antérieure avec la protection activée, elle reste active après la mise à jour. Ces versions ne retenaient pas le choix de protection, si bien que la v2026.1122.00 revenait avec la protection désactivée.
  - Windows (MSI) : juste avant de retirer l'ancienne version, l'installeur note si la protection tournait. Une fois l'installation réussie, la nouvelle version réactive la protection. Si l'installation échoue, rien ne change.
  - Linux (.deb) : le même relevé se fait pendant la mise à jour du paquet, avant le redémarrage du service.

## Notes de mise à niveau

- La mise à jour depuis la v2026.1122.00 ne demande rien de particulier : cette version retient déjà le choix de protection.
- Dans ces cas, la protection reste désactivée après une mise à jour depuis la v2026.1121.01 ou antérieure, comme avec la v2026.1122.00 ; réactivez-la dans l'application :
  - un autre administrateur que celui qui a configuré RouteWard fait la mise à jour ;
  - l'outil `reg.exe` est bloqué par une politique d'entreprise ;
  - la protection était en pause au moment de la mise à jour ;
  - la stratégie Windows qui désactive l'annulation des installations est active.

## Mise à niveau et vérification

- Windows : téléchargez `routeward-2026.1122.1-windows-x64.msi` (met à niveau les builds précédents via `MSI ProductVersion 26.11.2201`) ou `routeward-2026.1122.1-windows-x64.zip`.
- Linux : `sudo apt install ./routeward_2026.1122.1_amd64.deb`.
- Vérifiez les sommes de contrôle avec `SHA256SUMS.txt` ou les fichiers `.sha256` individuels.
