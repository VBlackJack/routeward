# RouteWard v2026.1115.01

Version correctif résolvant le lancement de l'application desktop Windows après installation `.msi` et intégrant la refonte du logo et de l'icône RouteWard.

## Corrections

- **Lancement après installation `.msi` (`HRESULT 0x80070005` Accès refusé)** : `routeward-desktop` (`wry::WebContext`) place désormais les données WebView2 dans `%LOCALAPPDATA%\RouteWard\WebView2` (`$XDG_DATA_HOME/routeward/webview` sous Linux) au lieu d'écrire dans `C:\Program Files\RouteWard\`.
- **Diagnostic au démarrage** : journalisation des erreurs fatales de fenêtre/WebView2 et affichage d'une boîte de dialogue Windows localisée (`errors.desktop.ui_init`) en cas d'échec d'initialisation.

## Modifications

- **Identité visuelle (`Prisme Passerelle`)** : refonte complète de `routeward-icon.svg`, `routeward-glyph.svg`, des PNG (`16` à `512 px`), de `routeward.ico`, des tampons RGBA et du repli SVG dans l'interface.

## Mise à jour Windows et vérification

- Télécharger `routeward-2026.1115.1-windows-x64.msi` (met à niveau `2026.1115.0` via `ProductVersion 26.11.1501`) ou `routeward-2026.1115.1-windows-x64.zip`.
- Contrôler les empreintes SHA-256 via `SHA256SUMS.txt` ou les fichiers `.sha256`.
