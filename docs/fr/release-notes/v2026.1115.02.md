# RouteWard v2026.1115.02

Version correctif résolvant le démarrage du démon privilégié après installation `.msi` et synchronisant la barre de titre Windows ainsi que les barres de défilement avec le thème ThemeForge actif.

## Corrections

- **Démarrage du démon Windows après installation `.msi`** : durcissement de la gestion des ACL et de la propriété d'un dossier `%ProgramData%\RouteWard` déjà existant (y compris création `ProgramDataComponents` dans le MSI avec droits `GenericAll` pour `SYSTEM` et `Administrators`), interdiction pour le processus UI non élevé de créer ou sonder les répertoires privilégiés, et séparation des journaux UI et démon.
- **Remontée des échecs de démarrage UAC** : `routeward-desktop` inspecte désormais le code de sortie précoce du processus enfant élevé `routeward daemon` pendant l'attente IPC au lieu d'échouer silencieusement sur expiration, et affiche la cause précise dans les notifications de l'interface (`NotElevated`, `InsecureProfile`, `IpcBindFailed`, `ConfigInvalid`, `DaemonExitedEarly`).
- **Exécution CLI directe** : `routeward run` vérifie l'élévation dès le lancement et renvoie des codes de sortie structurés via `std::process::ExitCode`.

## Modifications

- **Barre de titre native et barres de défilement thématisées** : synchronisation de la barre de titre Windows (fond, texte, bordure, mode clair/sombre via DWM et `tao::Window::set_theme`) ainsi que du `color-scheme` et des barres de défilement WebView (`scrollbar-color`, `scrollbar-width`, `::-webkit-scrollbar*`) avec le thème ThemeForge actif via `POST /api/theme`.

## Mise à jour Windows et vérification

- Télécharger `routeward-2026.1115.2-windows-x64.msi` (met à niveau `2026.1115.0` et `2026.1115.1` via `ProductVersion 26.11.1502`) ou `routeward-2026.1115.2-windows-x64.zip`.
- Contrôler les empreintes SHA-256 via `SHA256SUMS.txt` ou les fichiers `.sha256`.
