# RouteWard v2026.1124.00

A hardening, performance and accessibility release following a full codebase audit across the Rust daemon, desktop bridge, React UI, packaging and CI.

## Security

- **Hardened elevated daemon launch arguments (Windows).** `routeward-desktop` now validates the user SID before falling back to spawning a plain daemon and quotes arguments passed to `ShellExecuteExW` using Win32 `CommandLineToArgvW` rules.
- **Explicit System32 paths for Windows discovery tools.** Registry proxy detection (`reg.exe`) and Wi-Fi SSID detection (`netsh.exe`) now resolve through `windows_system_tool_path` instead of bare executable names.
- **Linux `.deb` `postinst` ignores test overrides as root.** `ROUTEWARD_CLI`, `ROUTEWARD_STATE_DIR`, `ROUTEWARD_STATUS_TIMEOUT` and `ROUTEWARD_SYSTEMD_DIR` are ignored whenever `postinst` runs under uid 0.
- **Unaligned IP Helper reads and Win32 tray re-entrancy safety.** `iphelper_rows` uses `read_unaligned` instead of casting `&[u8]` to aligned slices, and the Windows tray drops `RefCell` borrows before calling `Shell_NotifyIconW`.

## Performance and Reliability

- **Offloaded blocking I/O off Tokio workers.** Daemon profile saves, OS socket scans, named-profile CRUD, `FileLogger` error flushes (via a dedicated `Condvar`), and desktop diagnostic log bundling now run off the async worker pool.
- **Bounded SSE streams.** Desktop `/api/events` streams now enforce per-frame write timeouts and use a dedicated concurrency cap separate from short-lived `/api/*` requests.
- **40% smaller initial UI bundle.** Infrequent modals are lazy-loaded with `React.lazy`, `apps/desktop/build.rs` automatically embeds all generated `ui/dist/assets/*.{js,css}` chunks, and `App.tsx` uses `useSyncExternalStore` slice hooks with table row caps on live Activity/Logs views.

## Fixed

- **Consistent desktop bridge error reporting.** IPC errors on clear/flush/scan/test/profile endpoints are no longer swallowed, and all mutating routes return structured `{error, errorKey}` responses with consistent HTTP status codes.
- **Command Palette accessibility and Escape handling.** Restored a visible focus indicator, added `combobox`/`listbox`/`option` ARIA semantics and `scrollIntoView`, and fixed double `onClose` calls on Escape.
- **Jan-Sep CalVer release tag mapping.** Fixed leading-zero `MMDD` conversion in `release.yml` and `repo_guards.rs`, cleaned control characters in `CHANGELOG.md` with a new guard, and aligned Linux systemd test image dependencies.

## Upgrade Notes

- Nothing special: install over v2026.1123.01 or any earlier version. Your rules, profiles and protection state are kept.

## Upgrade and Verification

- Windows: download `routeward-2026.1124.0-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2400`) or `routeward-2026.1124.0-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1124.0_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
