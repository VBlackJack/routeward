# RouteWard v2026.1116.00

Feature release making Direct Filter Mode (no external proxy required) the default experience, removing misleading demo proxies, and adding one-click Edge and combined domain pattern rules.

## Changed

- **No More Demo Proxies**: Removed the misleading `127.0.0.1:1080` and `127.0.0.1:8080` demo proxies, demo chains, and hardcoded `proxy-socks5-primary` fallbacks from `configs/default_profile.json`, the Quick Setup wizard, and the Proxies, Rules, and Connections views. A fresh profile no longer contains any proxy node.
- **Direct Filter Mode by Default**: Direct Filter Mode is now a first-class default in `configs/system_constants.json`, the Dashboard, the Proxies view, the Quick Setup wizard, and the one-click use-case scenarios. External-proxy messaging is explicit, and `proxy` or `chain` rules are never created without an active proxy hop.
- **Simple Mode Rule Editing**: The Rules view gains a one-click `+ Edge (msedge.exe)` chip and optional combined domain patterns (such as `meshcore.net, *.meshcore.net`), with round-trip editing preserved in Simple Mode.

## Windows Upgrade and Verification

- Download `routeward-2026.1116.0-windows-x64.msi` (upgrades earlier `2026.1115.x` builds via `MSI ProductVersion 26.11.1600`) or `routeward-2026.1116.0-windows-x64.zip`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
