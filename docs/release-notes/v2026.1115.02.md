# RouteWard v2026.1115.02

Patch release resolving privileged daemon startup after MSI installation and synchronizing the native desktop title bar and WebView scrollbars with the active ThemeForge theme.

## Fixed

- **Windows Daemon Startup After MSI Install**: Hardened pre-existing `%ProgramData%\RouteWard` directory ACLs and ownership handling (including MSI `ProgramDataComponents` creation with `SYSTEM` and `Administrators` `GenericAll` permissions), fixed non-elevated GUI processes probing or creating privileged directories, and separated UI diagnostics logging from the elevated daemon log directory.
- **UAC Elevation Exit Reporting**: `routeward-desktop` now inspects early exit codes from the elevated `routeward daemon` child process (`h.try_exit_code()`) during UAC startup instead of failing silently on IPC timeout, surfacing specific error details in UI toast notifications (`NotElevated`, `InsecureProfile`, `IpcBindFailed`, `ConfigInvalid`, `DaemonExitedEarly`).
- **CLI Direct Execution Safety**: `routeward run` now enforces elevation upfront and propagates structured non-zero exit codes through `std::process::ExitCode`.

## Changed

- **Themed Native Title Bar and Scrollbars**: Synchronized the Windows desktop window caption, text, border, and light/dark DWM mode (`DwmSetWindowAttribute` + `tao::Window::set_theme`) as well as WebView `color-scheme` and scrollbars (`scrollbar-color`, `scrollbar-width`, `::-webkit-scrollbar*`) with the active ThemeForge palette via `POST /api/theme`.

## Windows Upgrade and Verification

- Download `routeward-2026.1115.2-windows-x64.msi` (upgrades `2026.1115.0` and `2026.1115.1` cleanly via `MSI ProductVersion 26.11.1502`) or `routeward-2026.1115.2-windows-x64.zip`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
