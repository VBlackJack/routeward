# RouteWard v2026.1115.01

Hotfix release resolving Windows desktop startup from per-machine `.msi` installations and updating the RouteWard brand icon and UI glyph.

## Fixed

- **Windows MSI Launch (`HRESULT 0x80070005` Access Denied)**: Configured `routeward-desktop` (`wry::WebContext`) to store WebView2 user data in `%LOCALAPPDATA%\RouteWard\WebView2` (and `$XDG_DATA_HOME/routeward/webview` on Linux) rather than writing beside the executable under `C:\Program Files\RouteWard\`.
- **Startup Diagnostics**: Added fatal window and WebView2 error logging plus a localized Windows `MessageBoxW` error prompt (`errors.desktop.ui_init`) so desktop initialization failures are never silent.

## Changed

- **Visual Identity (`Prisme Passerelle`)**: Updated `routeward-icon.svg`, `routeward-glyph.svg`, raster PNG sets (`16` to `512 px`), `routeward.ico`, raw RGBA buffers, and UI header fallback SVG.

## Windows Upgrade and Verification

- Download `routeward-2026.1115.1-windows-x64.msi` (upgrades `2026.1115.0` cleanly via `MSI ProductVersion 26.11.1501`) or `routeward-2026.1115.1-windows-x64.zip`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
