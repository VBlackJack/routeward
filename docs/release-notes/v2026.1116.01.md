# RouteWard v2026.1116.01

Security and reliability release from a full code audit: no more pre-emptive plaintext proxy credentials, a safer Windows service installation, a closed UDP fragment leak under the kill switch, bounded UDP telemetry, and real error reporting in the desktop UI.

## Security

- **Proxy credentials**: HTTP proxy `Basic` credentials are no longer sent before the proxy asks for them over a plaintext connection. They are sent after a `407` that offers `Basic`, with Negotiate and NTLM preferred, and stay pre-emptive only when the connection to the proxy uses TLS.
- **Windows service installation**: `install-service.ps1` copies the binaries to `%ProgramFiles%\RouteWard` before registering the LocalSystem service, and `routeward service install` refuses a binary whose file, folder or parent folders can be modified by non-administrators.
- **Elevated daemon hardening**: `reg`, `netsh`, `ipconfig` and `cmd` are resolved from the System32 folder, `WinDivert.dll` is only loaded from under the executable folder, and `ROUTEWARD_WINDIVERT_DLL_PATH` is only honoured by debug builds.
- **UDP fragments**: the first fragment of a fragmented UDP datagram now follows the routing rule and the kill switch instead of leaving unevaluated.
- **Name validation**: SNI and DNS names containing control characters or whitespace are rejected before they reach a `CONNECT` or SOCKS5 request, and SOCKS5 domain names longer than 255 bytes are refused instead of truncated.
- **Reply validation**: SOCKS5 UDP relay datagrams and direct DNS replies are only accepted from the expected source, and direct DNS transaction IDs are checked.
- **Linux IPv6 fallback**: with the kill switch on, the IPv6 nftables fallback rejects all IPv6 egress except loopback, RouteWard's own traffic and neighbour discovery, and startup fails if it cannot be installed.
- **Process attribution**: the WinDivert process cache is keyed by protocol, address family and port, purged when a socket closes, and kept for a shorter time.
- **Desktop API**: the UI page carries a Content-Security-Policy and every API route that changes state requires `POST`.

## Fixed

- **Error reporting**: the desktop bridge and the UI now report daemon errors with a 4xx or 5xx status and a translated message instead of returning success. Error messages stay on screen until dismissed.
- **System proxy toggle**: the toggle shows the real Windows setting when the UI starts.
- **UDP telemetry**: one record per UDP flow, closed after an idle timeout, instead of a new record that never closes for every datagram.
- **Regex rules**: `regex:` rules keep the case of their pattern (`\D`, `\W` and `\S` were turned into `\d`, `\w` and `\s`) and match case-insensitively. PAC files handle the prefix the same way.
- **Fake-IP pool**: allocation no longer overwrites a live mapping when the pool wraps around, and simultaneous lookups of the same domain share one address.
- **Process lookup on Windows**: connections are no longer blocked from time to time as "unknown process" when the system connection table grows during a lookup.
- **SOCKS5 UDP**: UDP associations work through TLS proxy nodes and IPv6 proxy hosts.
- **Linux Fake-IP guard**: the kernel drop rules follow the configured `fakeIpCidr`.
- **Engine start**: a listener that cannot bind now stops the engine start with an error instead of silently dropping traffic, and the engine can be stopped and started again in the same daemon.
- **Connection tracking**: NAT sessions expire, the pending SYN queue is bounded, and closing a relayed connection no longer lets the client's last packets leave unredirected.
- **UI**: editing a proxy keeps its imported SNI and enabled state, and an invalid imported palette no longer crashes the interface.
- **Windows service**: start, stop and registry cleanup failures are reported instead of ignored.

## Changed

- Connection updates are throttled and the log file stays open with a periodic flush (`logFlushIntervalMs`).
- Direct resolutions of Fake-IP targets, the system resolver list and the Linux conntrack table are cached.
- Accessibility: focus stays inside dialogs, form fields are labelled, connection rows can be selected with the keyboard, and the Dracula palette has a higher contrast secondary text color.
- New tunables in `configs/system_constants.json`: UDP flow idle timeout, telemetry update interval, process cache lifetime, NAT session expiry, SYN queue size, fragment verdict cache, relay close delay, DNS and conntrack caches.

## Upgrade Notes

- **Basic-only proxies over plaintext** now need one extra round trip on the first connection after each daemon start. Proxies using NTLM or Negotiate no longer receive the password in Basic form.
- **ZIP installations of the Windows service**: run `install-service.ps1` again. It copies the binaries to `%ProgramFiles%\RouteWard`, and a service registered from a folder that standard users can modify is refused.
- **WinDivert files** must sit under the RouteWard executable folder (next to `routeward.exe` or in `third_party\windivert\bin`). `ROUTEWARD_WINDIVERT_DLL_PATH` is ignored by release builds.
- **Scripts calling the local desktop API** must use `POST` for every route that changes state.
