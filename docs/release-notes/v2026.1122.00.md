# RouteWard v2026.1122.00

Protection that keeps running in the background, a one-click way to get the Internet back, and a beginner pass over the whole desktop app: setup assistant, Home status, pause, error messages and first run.

## Added

- **Protection that stays on**: RouteWard remembers whether you turned protection on and applies it again when the daemon starts, so protection survives closing the app, **Exit** and a reboot. Pauses are held by the daemon and resume on their own at the end, even after a reboot (`routeward ctl pause --seconds N`, `/api/engine/pause`).
- **Windows first start**: the first **Start protection** installs and starts the RouteWard service with a single administrator prompt, and RouteWard opens at sign-in in the system tray only (`--minimized`).
- **Get the Internet back**: `routeward recover` turns protection off and restores the Windows proxy settings RouteWard changed, without administrator rights. The MSI adds a **RouteWard - Restore Internet** Start menu shortcut, and the troubleshooting guide starts with a new "I have no Internet anymore" section.
- **Desktop**: only one RouteWard window at a time, the system proxy is repaired when the daemon stops answering and set again when it comes back, one-time explanations for closing to the tray and for **Exit**, tray notifications when an action fails, and the system language is used by default.
- **Desktop UI**: one clear protection status shared by the header, Home and the checklist (Stopped, Paused until HH:MM, Active, Error), a "Why?" panel per app in Activity, confirmation and undo for presets that change several settings, and a "Getting Started" section in the README for people with no networking knowledge.

## Changed

- **Simple mode rules**: one rule per app or site, `example.com` also covers its subdomains, app names without `.exe` are completed on Windows, and a single app rule now wins over a category card.
- **Wording**: error messages and tray texts rewritten in plain language, with a consistent vocabulary in English and French.

## Fixed

- **Proxy deletion and Make Primary**: Simple rules follow the new primary proxy (or are turned off) instead of pointing to a deleted proxy or silently going direct. Undoing a proxy deletion no longer claims a stored password.
- **Setup assistant**: a proxy link that cannot be read is kept with an explanation, a failed proxy is replaced when you try again, and a failed protection start is reported instead of showing a success message.
- **Rules**: "Show advanced fields" no longer drops what you typed (which could create a rule matching everything), and Activity quick actions update the existing rule instead of adding one that never applies.
- **Security**: the `url` dependency is updated to 2.5.9 (RUSTSEC-2026-0592).

## Upgrade Notes

- **Behaviour change on Windows**: with the service installed, **Exit** closes the app but keeps protection on. To stop it, use **Turn protection off** or **Pause** in the app or the tray, or the **RouteWard - Restore Internet** shortcut.
- The desktop app and the daemon must come from the same release: the MSI and the `.deb` update both together; with the portable ZIP, replace all files at once.
- No profile or configuration change is required. A new file, `protection_state.json`, is written next to the profile (`C:\ProgramData\RouteWard\` on Windows, `/etc/routeward/` on Linux).

## Upgrade and Verification

- Windows: download `routeward-2026.1122.0-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2200`) or `routeward-2026.1122.0-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1122.0_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
