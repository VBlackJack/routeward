# RouteWard v2026.1115.00

Initial public-ready release of RouteWard, an open-source, process-aware OS proxy router and egress firewall written in Rust for Windows and Linux.

## Highlights

- **OS-level Transparent Routing**: Intercepts TCP, UDP, and DNS connections per process on Windows (WinDivert) and Linux (`nftables` and `TPROXY`) across IPv4 and IPv6.
- **Upstream Protocols and Auth**: Supports SOCKS5 (TCP + UDP ASSOCIATE), SOCKS4 / SOCKS4a, HTTP CONNECT, and HTTPS CONNECT (TLS with optional `tlsSkipVerify`), including Windows SSPI (`Negotiate` / `NTLM`) authentication.
- **Chains, Failover, and Kill Switch**: Route traffic directly, block flows, forward through ordered proxy chains or failover groups, and prevent silent bypasses with Fake-IP (`198.18.0.0/15`), DNS-over-TCP, QUIC/LLMNR/mDNS/NetBIOS leakage guards, and strict kill-switch enforcement.
- **Microsoft Edge and Pattern-Based Browser Routing**: Inspects TLS SNI and HTTP `Host:` headers, evaluates `!pattern` exclusions, imports FoxyProxy JSON rules, and serves a loopback PAC script (`http://127.0.0.1:10811/proxy.pac`) with optional Windows `AutoConfigURL` integration.
- **Desktop App, Service, and CLI**: Includes the `routeward-desktop` GUI (Simple and Expert modes, visual System App Picker, named multi-profiles, system tray switcher, live connection telemetry with CSV/JSON export, EN/FR localization), Windows SCM service support, `routeward ctl`, and `routeward cleanup`.

## Windows Installation and Verification

- Download `routeward-2026.1115.0-windows-x64.msi` (per-machine installer with Start Menu shortcut) or `routeward-2026.1115.0-windows-x64.zip`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
- WinDivert note: if installed from the standard `.msi` build (without bundled WinDivert), run `fetch-windivert.ps1 -OutputDirectory "C:\Program Files\RouteWard"` in an elevated PowerShell prompt to download and verify WinDivert 2.2.2-A.
