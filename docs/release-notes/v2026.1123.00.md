# RouteWard v2026.1123.00

The RouteWard window now works on Linux, with a menu launcher and clear help when the service is not reachable. The command line speaks your system language.

## Fixed

- **Linux: the window opens and shows RouteWard.** Until now the desktop app closed at once on Wayland (the default session on Ubuntu) and showed an empty window on X11. It now works on both.
- **Linux: a clear message if the window cannot open.** An error window explains what to do and where the log is, instead of a hint about Microsoft Edge WebView2 written only to the log.

## Added

- **Linux: RouteWard in the applications menu.** The package installs a launcher and RouteWard icons, so you can start RouteWard like any other app and keep it in the dock.
- **Linux: help when the service is not reachable.** RouteWard tells you which of these applies and the command to type:
  - your account is not allowed to talk to the service yet: `sudo usermod -aG routeward $USER`, then log out and back in;
  - the service is not running: `sudo systemctl enable --now routeward`.
- **README: "Install on Linux"** with these steps.

## Changed

- **The command line follows your system language.** It used to answer in French everywhere. It now uses `--locale` or `ROUTEWARD_LOCALE` when you set them, and otherwise the language of your system.
- **Linux package:** WebKitGTK (`libwebkit2gtk-4.1-0`) and GTK (`libgtk-3-0`) are now required, so `apt` installs them with RouteWard.
- **The first window fits the screen** on small displays, on every system.

## Upgrade Notes

- Linux: the RouteWard service stays off after a first install. Turn it on once with `sudo systemctl enable --now routeward` and add your account to the `routeward` group (see above). Upgrades keep the current state.
- Scripts that read the French output of the command line should pass `--locale fr`. JSON output (`--json`) does not change.

## Upgrade and Verification

- Windows: download `routeward-2026.1123.0-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2300`) or `routeward-2026.1123.0-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1123.0_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
