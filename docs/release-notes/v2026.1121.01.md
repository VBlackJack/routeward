# RouteWard v2026.1121.01

Beginner UX polish, Windows System Tray status and quick controls, undo toasts, Before/After IP check, smart website rule ordering, and drag-and-drop import.

## Added

- **Windows System Tray**: dynamic colored status dot badges on the tray icon (green Protected, orange Paused, gray Offline), 1-click **Start Service** when offline, **Pause for 15 minutes** with cancellable auto-resume, and debounced native Windows warning notifications (`NIF_INFO`) when a proxy outage triggers the kill-switch.
- **Simple mode safety and convenience**: **Undo** buttons in rule and proxy deletion toasts, 1-click **Paste from Clipboard** proxy import on Home and My Proxy, **Make Primary** proxy promotion (`SetPrimaryProxy` IPC and `/api/proxies/set-primary`), and a 1-click **Router & Printers (Local Network)** compatibility pack.
- **Diagnostics and rule clarity**: Before/After IP check (`/api/system/direct-ip`) inside **Verify My Protection**, a plain-language **"Where does a website go?"** site tester, shadowed-rule warnings with 1-click **Move First**, and window-wide drag-and-drop import for `.json` profiles, FoxyProxy exports, and `.txt` proxy lists.

## Changed

- **Simple mode architecture and polish**: extracted `SimpleDashboardView.tsx`, decluttered the Home banner, made the 3-step readiness checklist clickable, added a close button and paused-state notice to **Verify My Protection**, assigned higher default priority (`8`) to website-specific rules so site exceptions win over generic browser rules, humanized error messages in `TroubleshootModal`, displayed friendly application names in Activity, and wired Simple mode failover so all simple proxy rules route through `chain-simple-failover`.
- **Documentation**: added a Beginner Quick-Fixes section to both English and French troubleshooting guides.

## Fixed

- **RulesView**: visual application cards no longer appear active or blocked before any rule exists.
- **QuickSetupWizardModal**: newly entered proxies can be tested before applying without creating duplicate entries.

## Upgrade Notes

- No breaking profile or configuration change. Desktop and daemon from v2026.1121.00 and v2026.1121.01 remain compatible.

## Upgrade and Verification

- Windows: download `routeward-2026.1121.1-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2101`) or `routeward-2026.1121.1-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1121.1_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
