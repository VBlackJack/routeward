# RouteWard v2026.1123.01

A small wording fix: the telemetry texts now fit every system.

## Fixed

- **Telemetry texts no longer say "Windows" everywhere.** On Linux, the setup assistant said it would "block Windows telemetry". The assistant, its summary, the rules help and the French name of the telemetry rule pack now speak of background telemetry from your system and apps. What the protection blocks does not change.

## Upgrade Notes

- Nothing special: install over v2026.1123.00 or any earlier version. Your rules, profiles and protection state are kept.

## Upgrade and Verification

- Windows: download `routeward-2026.1123.1-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2301`) or `routeward-2026.1123.1-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1123.1_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
