# RouteWard v2026.1115.03

Patch release fixing false daemon disconnects on large connection lists, surfacing engine toggle errors in the UI, and making browser and CLI tool rules safe by default.

## Fixed

- **IPC Line Limit and Connection History**: Raised `ipc.maxLineBytes` to 8 MiB and bounded tracked connection history (`telemetry.maxConnectionHistoryEntries` = 500, preserving active connections) across the daemon, the desktop command bridge, and the UI store, so large connection lists no longer break Named Pipe IPC.
- **Engine Toggle Errors**: `IpcClient::call_typed_detailed` now distinguishes IPC transport drops from live daemon application errors (`ok: false`), and structured `/api/engine/toggle` errors (`400`, `409`, `503`) are shown as localized toasts in the Header, Dashboard, and Command Palette controls.
- **Quick Setup Wizard**: Rule IDs (`rule-wiz-<preset>`) are deduplicated, proxy and rule saves are awaited sequentially, and concurrent wizard submissions are prevented.
- **WinDivert DLL Resolution**: Relative `windivertDllPaths` entries are resolved against the executable directory before the current working directory, and Windows `\\?\` verbatim prefixes are stripped before loading `WinDivert.dll`.

## Changed

- **Safe Default Rules**: `rule-browsers-socks5` and `rule-cli-tools-chain` now default to `enabled: false` in `configs/default_profile.json`, so browsers and CLI tools pass through cleanly until explicitly routed or enabled.

## Windows Upgrade and Verification

- Download `routeward-2026.1115.3-windows-x64.msi` (upgrades earlier `2026.1115.x` builds via `MSI ProductVersion 26.11.1503`) or `routeward-2026.1115.3-windows-x64.zip`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
