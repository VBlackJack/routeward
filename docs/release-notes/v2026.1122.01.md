# RouteWard v2026.1122.01

Upgrading from an older version now keeps your protection on.

## Fixed

- **Upgrade keeps protection on**: when you upgrade from v2026.1121.01 or earlier with protection turned on, it is still on after the upgrade. Those versions did not remember the protection choice, so v2026.1122.00 came back with protection off.
  - Windows (MSI): just before the old version is removed, the installer notes whether protection was running. Once the installation has succeeded, the new version turns protection back on. If the installation fails, nothing changes.
  - Linux (.deb): the same check runs during the package upgrade, before the service restarts.

## Upgrade Notes

- Upgrading from v2026.1122.00 needs nothing special: that version already remembers the protection choice.
- In these cases protection stays off after an upgrade from v2026.1121.01 or earlier, as with v2026.1122.00; turn it back on in the app:
  - a different administrator than the one who set up RouteWard runs the upgrade;
  - the `reg.exe` tool is blocked by a company policy;
  - protection was paused at the time of the upgrade;
  - the Windows policy that disables installation rollback is set.

## Upgrade and Verification

- Windows: download `routeward-2026.1122.1-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2201`) or `routeward-2026.1122.1-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1122.1_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
