# RouteWard v2026.1122.01

See what RouteWard blocked and why, unblock it in one click, and understand a block from the logs. Upgrading from an older version now keeps your protection on.

## Added

- **Blocked tab**: Activity lists every blocked connection by app and by site, with the reason in plain words (a blocking rule, a proxy that is down or refuses the connection, the safety cut-off, a proxy that cannot carry UDP, QUIC or encrypted DNS, an unknown app...), the rule that applied, the last time and the count. Home shows a shortcut when something was blocked.
- **Unblock in one click**: choose 15 minutes, 1 hour or always. Before anything changes, RouteWard shows the rule it will add and checks that the connection will really go through. An Undo button follows. A temporary unblock removes itself when it expires. The safety cut-off is never turned off for everything.
- **Logs**: search text, filter by component, period and level, open the logs of previous days, and jump from a blocked item or a connection straight to its log lines.
- **Check-up**: a built-in analysis explains the known causes of a block (proxy unreachable or rejecting the password, a rule that blocks an app, a rule hidden by another one, protection paused...) with a button to fix each one.
- **Diagnostic export**: one file to share when you ask for help, without passwords, tokens, user names or machine name, with an option to hide the sites you visited. The dialog shows what the file contains before you save it, and an existing file is never overwritten.
- **Command line**: `routeward ctl logs`, `ctl blocked`, `ctl diagnose` and `ctl export-diagnostics` do the same from a terminal.
- **Log retention**: daemon, desktop and command line logs are kept 14 days.

## Fixed

- **Upgrade keeps protection on**: when you upgrade from v2026.1121.01 or earlier with protection turned on, it is still on after the upgrade. Those versions did not remember the protection choice, so v2026.1122.00 came back with protection off.
  - Windows (MSI): just before the old version is removed, the installer notes whether protection was running. Once the installation has succeeded, the new version turns protection back on. If the installation fails, nothing changes.
  - Linux (.deb): the same check runs during the package upgrade, before the service restarts.

## Upgrade Notes

- Upgrading from v2026.1122.00 needs nothing special: that version already remembers the protection choice.
- In these cases protection stays off after an upgrade from v2026.1121.01 or earlier, as with v2026.1122.00; turn it back on in the app:
  - a different administrator than the one who set up RouteWard runs the upgrade;
  - the `reg.exe` tool is blocked by a company policy;
  - protection was paused at the time of the upgrade;
  - the Windows policy that disables installation rollback is set.

## Upgrade and Verification

- Windows: download `routeward-2026.1122.1-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2201`) or `routeward-2026.1122.1-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1122.1_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
