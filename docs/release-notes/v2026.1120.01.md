# RouteWard v2026.1120.01

Maintenance release: the Linux package runs cleanly on Debian 12, and follow-up fixes to the blocked-traffic answers and the DNS server exemption introduced in v2026.1120.00.

## Fixed

- **Linux package**: the `.deb` is now built against glibc 2.35, so on Debian 12 the binaries no longer print "weak version `GLIBC_2.39' not found" on every start (terminal and service journal). It runs on Debian 12, Ubuntu 22.04 and newer.
- **Blocked UDP (Windows)**: at most one injected ICMP Port Unreachable per flow and second, so an application that retransmits a blocked datagram no longer makes RouteWard forge one message per packet.
- **DNS servers on the host (Windows)**: a DNS server process whose image cannot be queried is identified by the name RouteWard already knows, so a Block rule naming it still applies.
- **Profile reload**: no longer stalls the engine while DNS server processes are scanned and firewall rules are reapplied.
- **Documentation**: on Windows a directed broadcast (for example 192.168.1.255) is answered like a unicast address; only multicast and 255.255.255.255 stay silent.

## Upgrade Notes

- No profile or configuration change. Desktop and daemon from v2026.1120.00 and v2026.1120.01 work together.

## Upgrade and Verification

- Windows: download `routeward-2026.1120.1-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2001`) or `routeward-2026.1120.1-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1120.1_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
