# RouteWard v2026.1121.00

Beginner-friendly Simple mode overhaul, guided troubleshooting, existing proxy discovery, Wi-Fi auto profile switching, and Windows portable ZIP bundling WinDivert 2.2.2.

## Added

- **Simple mode onboarding and protection check**: 1-click **Start Protection** on Home when the Windows service is stopped, a 3-step readiness checklist, temporary pause (`15m` / `1h`) with automatic resume countdown, a 1-click **Verify My Protection** summary, a guided **App not working?** troubleshooter to unblock apps or sites in Direct mode, and a dismissible proxy outage alert banner.
- **Zero-jargon proxy setup and discovery**: proxy link pasting directly in Simple mode (button and quick-paste auto-fill in Add Proxy), manual host/port input and live connection testing in the 3-step wizard, a 1-click **Automatic Backup Proxy Switch** (failover) toggle when two or more proxies are active, and **Detect Existing Proxy** (`/api/system/detect-proxies`) to discover Windows registry, environment, Tor, or local SSH/HTTP proxies.
- **Everyday app and site routing**: automatic URL normalization for website rules (`https://www.example.com/login` expands to `example.com, *.example.com`), a searchable running/installed PC apps panel, 1-click protection packs (Ads & Trackers, OS & App Telemetry, Focus Mode), 2-step keyboard-accessible delete confirmations (with in-use warnings on proxies), a **Restore Default Settings** safety reset with automatic profile backup, an expandable **Advanced Tools** accordion in Settings, and Wi-Fi network-based automatic profile switching (`/api/system/network-info`).

## Changed

- **Windows portable ZIP**: bundles unmodified WinDivert 2.2.2 (`WinDivert.dll` and `WinDivert64.sys`, LGPLv3, with `THIRD_PARTY_NOTICES.txt` and the upstream license) alongside `fetch-windivert.ps1`, so transparent interception works right after extraction.
- **Desktop UI polish**: added global `:focus-visible` keyboard outlines, larger icon button hitboxes, actionable proxy error messages, and inline port validation (`1-65535`).

## Fixed

- **Process Launcher**: displays the actual HTTP relay port (`relayHttpEndpoint`) for `HTTP_PROXY` / `HTTPS_PROXY` instead of the SOCKS5 port.
- **Quick Setup Wizard**: the Gaming goal now creates the gaming direct rule consistently with the Home scenario card.
- **Tooling and tests**: `ui/scripts/audit.mjs` no longer emits Node `DEP0190` on Windows, and `App.test.tsx` no longer emits React `act(...)` warnings.

## Upgrade Notes

- No breaking profile or configuration change. Desktop and daemon from v2026.1120.01 and v2026.1121.00 remain compatible.

## Upgrade and Verification

- Windows: download `routeward-2026.1121.0-windows-x64.msi` (upgrades earlier builds via `MSI ProductVersion 26.11.2100`) or `routeward-2026.1121.0-windows-x64.zip`.
- Linux: `sudo apt install ./routeward_2026.1121.0_amd64.deb`.
- Verify checksums against `SHA256SUMS.txt` or the individual `.sha256` files.
